Documentation: driverUpdate.ps1

Project path: src/driverUpdate.ps1

Purpose: This script checks which driver updates are currently offered by Windows Update / Microsoft Update, shows the results in a readable list, and asks whether those updates should be installed. It uses the built-in Windows Update Agent instead of downloading drivers from random websites.

1. How the script works

  1. Creates a Windows Update Agent session through the COM interface.
  2. Searches for updates matching Type='Driver' that are not installed and not hidden.
  3. Shows each available driver update with title, categories, approximate size, and reboot hint.
  4. Prompts the user to install all, some, or none of the listed updates.
  5. If installation is chosen, accepts any needed EULAs, downloads the driver updates, and starts installation.
  6. Prints per-item results and warns if a reboot is required.

Why this is the safer approach

  • Uses Windows Update / Microsoft Update rather than scraping vendor download pages.
  • Does not execute unknown installers from the web.
  • Keeps the user in control by asking before installation unless -AutoYes is used.

2. Usage

Basic scan with install prompt:

powershell -ExecutionPolicy Bypass -File .\src\driverUpdate.ps1

List only, do not install anything:

powershell -ExecutionPolicy Bypass -File .\src\driverUpdate.ps1 -ListOnly

Install everything offered without extra prompt:

powershell -ExecutionPolicy Bypass -File .\src\driverUpdate.ps1 -AutoYes

Run without color:

powershell -ExecutionPolicy Bypass -File .\src\driverUpdate.ps1 -NoColor
Important: Installing driver updates usually requires an elevated PowerShell window (Run as Administrator). A non-elevated session can still be used for scanning.

3. Parameters

ParameterMeaning
-ListOnlyOnly scan and list driver updates. No installation is started.
-AutoYesAutomatically select all offered updates for installation after the scan.
-NoColorPrint plain text output without colored headings or status lines.

4. Setup instructions for another user

  • Use Windows 10 or Windows 11 with PowerShell 5.1 or later.
  • Make sure the Windows Update service is enabled and the machine has internet access.
  • Open PowerShell as Administrator if you want to install updates, not just list them.
  • Run -ListOnly first on a new system to confirm what the machine sees through Windows Update.

5. Current state

Implemented now:
  • Trusted driver update scan through the Windows Update Agent.
  • Readable listing of offered driver updates.
  • Interactive selection of all, some, or none of the updates.
  • Installation workflow with download and result reporting.
  • Reboot-required hint after installation.

Known limitations

  • The script sees the drivers that Windows Update / Microsoft Update offers to the system. OEM utilities may still provide newer or more device-specific packages.
  • Some vendors distribute BIOS, firmware, GPU, or docking-station updates only through their own trusted tools.
  • A successful installation may still require a reboot before the driver is fully active.

6. Troubleshooting

  • Search fails: check that the Windows Update service is enabled and the PC can contact Microsoft update services.
  • Install fails immediately: reopen PowerShell as Administrator and try again.
  • No updates found: that usually means Windows Update is not offering newer drivers right now; this is not always an error.
  • Need vendor-specific updates: use the trusted OEM tool for your hardware vendor if it is already installed on the machine.
