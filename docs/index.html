ScriptBox Documentation

This folder contains browser-friendly documentation for the PowerShell scripts in src/. Open the pages below in any browser; no LaTeX installation is required.

newsUpdate.ps1

Explains how the personalized news briefing script works, how another user can configure it, and the current implementation status with next steps.

welcome.ps1

Explains how the startup window-layout script works, how to set it up on a new machine, and what improvements are planned.

Linux / Cross-Platform

Guides for using the bash/shell versions of the scripts on Linux and macOS, including setup, dependencies, and Linux-specific considerations.

installList.ps1

Smart program installer that automatically detects and uses the best installation method (Winget, Chocolatey, or official downloads) for Windows software.

installList.sh

Linux bash installer with interactive package selection and safe install strategy (apt/dnf/pacman first, then flatpak/snap, then official links).

driverUpdate.ps1

Checks which driver updates Windows Update currently offers, asks what to install, and uses the built-in Windows Update Agent for a safer workflow.

driverUpdate.sh

Linux driver and firmware update helper that checks fwupd, Ubuntu driver recommendations, and distro package-manager updates before asking to install them.
