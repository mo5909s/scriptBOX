ScriptBox Documentation

This folder contains browser-friendly documentation for the PowerShell scripts in src/. Open the pages below in any browser; no LaTeX installation is required.

newsUpdate.ps1

Explains how the personalized news briefing script works, how another user can configure it, and the current implementation status with next steps.

welcome.ps1

Explains how the startup window-layout script works, how to set it up on a new machine, and what improvements are planned.
