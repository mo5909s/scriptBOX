Documentation: installList.ps1

Project path: src/installList.ps1

Purpose: This script provides a safe, interactive way to install Windows software by automatically detecting and using the best available package manager (Winget or Chocolatey) with fallback to official downloads. It maintains an expandable database of common programs and validates installations.

1. How the script works

Main execution flow

  1. Detects available package managers (Winget, Chocolatey).
  2. Displays an interactive menu of available programs to install.
  3. User selects which programs they want to install.
  4. Script determines the best installation method for each selected program.
  5. Validates that programs are not already installed.
  6. Shows an installation plan for user confirmation.
  7. Executes installations using the chosen method.
  8. Reports success/failure status for each program.

Installation method hierarchy

For each program, the script tries methods in this order:

  1. Winget — Built-in on Windows 11 and later; fastest and safest
  2. Chocolatey — Community package manager; requires prior installation
  3. Website fallback — Provides the official download URL for manual installation

Important features

  • Pre-installation check: Verifies program is not already installed before attempting installation.
  • Safe by default: Shows confirmation prompt before making any changes.
  • Dry-run mode: Preview what would happen without executing anything.
  • Detailed reporting: Shows success/skip/failure status for each program.
  • Expandable database: Easy to add new programs to the list.

2. Setup and prerequisites

Requirements

  • Windows 10 or later
  • PowerShell 5.1 or later (included with Windows)
  • Administrator privileges (required for installation)
  • Internet access

Recommended setup

For best results, install Winget (available natively on Windows 11) or Chocolatey.

To install Chocolatey:

powershell -ExecutionPolicy Bypass -Command "& {$(irm https://community.chocolatey.org/install.ps1)}"

To update Winget on Windows 10:

Winget is included on Windows 11+. For Windows 10, download the latest release from GitHub.

3. Usage examples

Basic usage

Run the script and select programs interactively:

powershell -ExecutionPolicy Bypass -File .\src\installList.ps1

Dry-run mode (preview without changes)

powershell -ExecutionPolicy Bypass -File .\src\installList.ps1 -DryRun

Skip confirmation prompt

powershell -ExecutionPolicy Bypass -File .\src\installList.ps1 -SkipConfirmation

Enable verbose output

powershell -ExecutionPolicy Bypass -File .\src\installList.ps1 -Verbose

6. Adding new programs

To add a new program, edit the $ProgramDatabase array in the script and add an entry like this:

@{
    Name = "Program Name"
    Winget = "Vendor.Program"
    Chocolatey = "program"
    Website = "https://official-download-url.com"
    Description = "Brief description"
}
