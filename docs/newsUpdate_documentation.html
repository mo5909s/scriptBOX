Documentation: newsUpdate.ps1

Project path: src/newsUpdate.ps1

Purpose: This script creates a personalized news briefing by combining NewsAPI results, optional Hacker News results, a daily recipe from TheMealDB, and an optional AI-generated summary. It can print to the terminal, save to a text file, and generate a browser dashboard.

1. How the script works

Main execution flow

  1. Reads script parameters such as API keys, tags, language, output settings, and browser options.
  2. Checks whether a placeholder NewsAPI key is still being used.
  3. Fetches one deterministic recipe of the day using TheMealDB.
  4. Loops over each configured tag and collects matching articles.
  5. Pulls news from NewsAPI and, unless disabled, from Hacker News Algolia.
  6. Normalizes the results into a common internal structure.
  7. Optionally sends collected headlines to the GitHub Copilot endpoint for a short summary.
  8. Prints a formatted briefing in the terminal.
  9. Optionally saves the terminal output to a text file.
  10. Optionally generates an HTML file and opens it in the default browser.

Important functions

FunctionWhat it does
Write-ColorWrites colored console output unless browser-only mode is active.
HtmlEncEscapes text before inserting it into generated HTML.
Get-DailyRecipeChooses a recipe deterministically by day-of-year so the recipe changes daily but stays stable throughout the day.
Get-NewsEverything / Get-NewsTopHeadlinesCalls the NewsAPI endpoints and returns article data.
Get-HackerNewsForTagFetches matching stories from the HN Algolia API.
Get-AiSummaryUses the provided GitHub token to ask the Copilot chat endpoint for a short summary.
Format-PublishedAtConverts ISO date strings to local time in dd.MM.yyyy HH:mm format.
EmitCentral helper for terminal output and optional file saving.

Output modes

  • Terminal mode: default behavior.
  • File mode: enable -SaveToFile and optionally set -OutputPath.
  • Browser mode: enable -OpenInBrowser to keep terminal output and also open HTML.
  • Browser-only mode: enable -BrowserOnly to suppress terminal output.

2. Setup instructions for another user

Prerequisites

  • Windows PowerShell or PowerShell capable of running .ps1 scripts.
  • Internet access.
  • A NewsAPI key from newsapi.org.
  • Optional: a GitHub token if AI summaries should be enabled.
Important: The script currently contains a hardcoded default value for $NewsApiKey. A new user should not rely on that and should pass their own key explicitly or move secrets to environment variables or another secure place.

Recommended first run

powershell -ExecutionPolicy Bypass -File .\src\newsUpdate.ps1 `
  -NewsApiKey "<YOUR_NEWSAPI_KEY>" `
  -Tags "technology","AI","science" `
  -ArticlesPerTag 3

Browser dashboard example

powershell -ExecutionPolicy Bypass -File .\src\newsUpdate.ps1 `
  -NewsApiKey "<YOUR_NEWSAPI_KEY>" `
  -OpenInBrowser `
  -SaveToFile

Settings users typically change

ParameterTypical use
-NewsApiKeyAlways set your own key when sharing or onboarding a new user.
-GitHubTokenOptional; enables AI summaries.
-TagsMain personalization setting; choose the topics the user actually cares about.
-ArticlesPerTagIncrease for more detail or reduce for a shorter morning briefing.
-LanguageChange the preferred NewsAPI language.
-TopHeadlinesUse top headlines instead of the broader everything search.
-DisableHackerNewsUseful if the user wants only conventional news sources.
-NoColorUseful for plain terminals or log captures.
-SaveToFile / -OutputPathUseful for keeping a copy of the briefing.
-OpenInBrowser / -BrowserOnlyUseful if the user prefers a visual dashboard.

Quick checklist for handover

  • Tell the new user to bring their own API keys and tokens.
  • Let them choose their own tags and language.
  • Have them test terminal mode first before enabling browser mode and AI summaries.
  • If this is used on a schedule, prefer passing secrets via a secure external configuration method.

3. Current state

Implemented now:

  • Daily recipe recommendation from TheMealDB.
  • Optional AI summary generation.
  • Terminal, text-file, and browser output modes.
  • Basic error handling around external API calls.

Known limitations

  • External API availability and quotas affect the results.
  • Similar stories can appear more than once because deduplication is not implemented.
  • HTML output is written to a temporary file by default.
  • AI summaries depend on a valid token and compatible endpoint behavior.

4. Troubleshooting

  • Script does not start: try running with -ExecutionPolicy Bypass.
  • No articles found: use broader tags such as technology or disable -TopHeadlines.
  • NewsAPI errors: verify key validity and quota.
  • No AI summary: check the GitHub token and leave the feature disabled if not needed.
  • Browser did not open: verify file associations and try -OpenInBrowser again.
