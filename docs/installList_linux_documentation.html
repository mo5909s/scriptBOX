Documentation: installList.sh

Path: src/installList.sh

Purpose: Linux installer helper that asks which programs to install and chooses the safest available route: distro packages first, then Flatpak/Snap, then official website fallback.

1. Safety model

  1. Use native package manager (apt, dnf, pacman) when available.
  2. Fallback to flatpak or snap.
  3. If no safe automated route exists, print official download URL instead of running unknown installers.

2. Supported programs

  • Firefox
  • VLC
  • Git
  • Node.js
  • Python
  • VS Code
  • Discord
  • 7-Zip (or p7zip package equivalent)

3. Setup and usage

Make executable:

chmod +x ./src/installList.sh

Run interactive install:

./src/installList.sh

Dry run (no changes):

./src/installList.sh --dry-run

Skip confirmation prompt:

./src/installList.sh --yes

4. Example: Firefox install

./src/installList.sh --yes
# select option: 1

5. Troubleshooting

  • Permission denied: run chmod +x ./src/installList.sh.
  • No supported backend: install one of apt, dnf, pacman, flatpak, snap.
  • Install fails: retry manually using the printed package name or official URL.
Note: Package names can vary by distro. If a package is unavailable, use the shown official URL fallback.
