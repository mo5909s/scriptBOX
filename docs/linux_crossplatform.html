Linux / Cross-Platform Usage

ScriptBox now includes bash/shell script versions for Linux and macOS compatibility.

1. Overview: What works on Linux

ScriptWindows (PowerShell)Linux/macOS (Bash)Notes
newsUpdate ✓ Full feature ✓ Full feature Both versions fetch from NewsAPI, HN Algolia, TheMealDB. Browser opening uses xdg-open (Linux) or open (macOS).
welcome ✓ Full (with window tiling) ⚠ Partial (app launch only) PS1 version tiles windows. Bash version launches apps but does not tile; use wmctrl or a tiling window manager for that.
driverUpdate ✓ Driver scan/install via Windows Update Agent ⚠ Partial, distro-specific Bash version checks trusted Linux channels such as fwupdmgr, ubuntu-drivers, and driver-related package updates. Coverage depends on distro and hardware vendor.

2. newsUpdate (Bash/Linux version)

Location

src/newsUpdate.sh

Prerequisites

  • Bash 4.0+
  • curl (for API calls)
  • jq (for JSON parsing) — optional but recommended
  • Internet access
  • NewsAPI key from newsapi.org

Install dependencies (Ubuntu/Debian)

sudo apt-get update
sudo apt-get install curl jq

Setup and usage

Make the script executable:

chmod +x ./src/newsUpdate.sh

Run with your own NewsAPI key:

export NEWS_API_KEY="your_api_key_here"
./src/newsUpdate.sh

Or pass the key as a parameter:

./src/newsUpdate.sh -NewsApiKey "your_api_key_here" -Tags "technology" -ArticlesPerTag 3

Behavior differences from PowerShell version

  • Browser opening uses xdg-open on Linux (respects your default browser) or open on macOS.
  • Color output is ANSI-based (should work in most Linux/macOS terminals).
  • Without jq, JSON parsing falls back to basic patterns; jq is strongly recommended for reliable parsing.
  • Recipe rotation is deterministic by day-of-year, same as the PowerShell version.

Common parameters

./src/newsUpdate.sh \
  -NewsApiKey "your_key" \
  -Tags "AI,space,technology" \
  -ArticlesPerTag 5 \
  -Language en \
  -TopHeadlines \
  -SaveToFile \
  -NoBrowser

3. welcome (Bash/Linux version)

Location

src/welcome.sh

What it does

  • Launches or reuses Thunderbird, Spotify, and Todoist (or similar).
  • Optionally plays a startup audio file.
  • Does not tile windows (window tiling is environment-specific).

Prerequisites

  • Bash
  • The target applications installed: thunderbird, spotify, todoist (or alternatives)
  • Optional: audio player such as paplay, ffplay, or mpv

Setup and usage

Make the script executable:

chmod +x ./src/welcome.sh

Run normally:

./src/welcome.sh

Dry-run mode (show what would happen without launching apps):

./src/welcome.sh -DryRun

Skip startup audio:

./src/welcome.sh -SkipStartupAudio

Install audio player (if you want startup sound)

Ubuntu/Debian:

sudo apt-get install pulseaudio-utils
# or
sudo apt-get install ffmpeg
# or
sudo apt-get install mpv

Window tiling on Linux

Important: This bash version does not tile windows. Window tiling is not portable because different Linux desktop environments (X11, Wayland, i3, GNOME, KDE) handle it differently.

If you want window tiling on Linux, you have options:

  • Use a tiling window manager: i3, awesome, sway, dwm. These tile windows automatically.
  • Use wmctrl: Can move and resize windows on X11. Example: 
    wmctrl -r "Thunderbird" -b add,maximized_vert,maximized_horz
  • Use xdotool: Another X11 window manipulation tool.

4. driverUpdate (Bash/Linux version)

Location

src/driverUpdate.sh

What it does

  • Checks firmware updates via fwupdmgr when available.
  • Checks Ubuntu recommended driver changes via ubuntu-drivers when available.
  • Checks distro package manager updates for common driver-related packages.
  • Asks before applying each category of updates.

Basic usage

chmod +x ./src/driverUpdate.sh
./src/driverUpdate.sh --list-only

Apply everything with prompts auto-accepted:

./src/driverUpdate.sh --yes

Documentation page: driverUpdate.sh documentation

Important: Linux driver delivery is not standardized the way Windows Update is. The script intentionally uses only trusted channels already configured on the machine; it does not search random vendor sites.

5. Environment variables

Instead of passing parameters every time, you can set environment variables:

VariableUsed byExample
NEWS_API_KEYnewsUpdate.shexport NEWS_API_KEY="abc123..."
GITHUB_TOKENnewsUpdate.shexport GITHUB_TOKEN="ghp_..."

Add them to your ~/.bashrc or ~/.zshrc to make them permanent:

echo 'export NEWS_API_KEY="your_key_here"' >> ~/.bashrc
source ~/.bashrc

6. Scheduling on Linux

Use cron to run newsUpdate automatically:

crontab -e

Example: Run at 8 AM every weekday:

0 8 * * 1-5 /path/to/newsUpdate.sh -NoBrowser -SaveToFile

7. Troubleshooting

  • Command not found: Make sure the script is executable: chmod +x script.sh
  • Permission denied: Check file permissions: ls -la src/
  • jq not found: Install it: sudo apt-get install jq (recommended)
  • curl fails: Check internet connection and firewall rules.
  • Browser does not open: Ensure xdg-open (Linux) or open (macOS) works, or use -NoBrowser.
  • Audio player not found: Install one: paplay, ffplay, or mpv.
